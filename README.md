## Локальный просмотр

Сборка не нужна — это статические файлы. Достаточно любого статического сервера
из корня репозитория:

```bash
python3 -m http.server 4173
```

Затем открыть <http://localhost:4173/404.html>.

## Фон страницы 404

В макете фон — это растровая картинка с боке-частицами и заливкой
`rgba(0, 0, 0, 0.4)` сверху. В коде она заменена на два независимых слоя:

1. **Градиентная туманность** (`.space` в CSS) — тёплое золото сверху слева,
   холодный синий снизу справа. Остаётся резкой на любом разрешении и не зависит
   от внешнего файла.
2. **Живое поле частиц** (`ParticleField` на canvas) — рисуется поверх градиента.

### Движок частиц

`assets/js/particle-field.js` — самостоятельный ES-модуль без зависимостей.

**Объём.** У каждой частицы есть глубина `z`. Она определяет размер
(квадратично, поэтому перспектива читается сильнее), расфокус относительно
фокальной плоскости и прозрачность. Ближние частицы — крупные размытые боке,
дальние — мелкие и резкие. Спрайты предрендерятся один раз в офскрин-canvas по
шести уровням размытия, поэтому в кадре нет ни одного дорогого `shadowBlur`.

**Движение разделено на два независимых слоя**, чтобы они не конфликтовали:

- *Ambient drift* — медленное поле потока из больших синусоид плюс личный дрейф
  каждой частицы. Работает всегда и никогда не затухает.
- *Pointer wind* — дополнительная скорость от движения мыши, которая затухает до
  нуля. Именно поэтому поле плавно замедляется, а не останавливается резко.

**Разгон мышью.** Скорость курсора сглаживается экспоненциально
(`pointerTau = 0.35 s`), затем передаётся частицам с коэффициентом
`coupling = 0.16`. Частицы набирают и теряют эту скорость с постоянной времени
`responseTau = 1.5 s` — отсюда долгое планирование после остановки курсора.
Ближние частицы отвечают на ветер сильнее дальних, что даёт параллакс. Рядом с
курсором добавляется локальный завихрённый толчок, поэтому поле «расходится»
перед мышью, а не просто сдвигается.

Всё сглаживание сделано через `1 - exp(-dt / tau)`, поэтому поведение не зависит
от частоты кадров.

Параметры настраиваются через второй аргумент конструктора:

```js
new ParticleField(canvas, {
  coupling: 0.16,     // насколько сильно мышь разгоняет частицы
  responseTau: 1.5,   // инерция: больше — дольше планируют
  pointerTau: 0.35,   // сглаживание курсора: больше — мягче старт
  maxWind: 260,       // потолок скорости от мыши, css px/s
  swirlRadius: 260,   // радиус локального завихрения вокруг курсора
});
```

Амплитуда фонового дрейфа подобрана по измерениям: при вдвое меньших значениях
поле визуально читается как статичная картинка. Разгон от мыши остаётся примерно
в восемь раз сильнее дрейфа, поэтому реакция на курсор хорошо заметна на фоне
постоянного движения.

**Производительность и доступность.** Количество частиц считается от площади
вьюпорта (одна на ~9200 px², но не больше 190), DPR ограничен двойкой, `rAF`
останавливается на скрытой вкладке, `dt` в кадре ограничен сверху. При
`prefers-reduced-motion: reduce` рисуется один статичный кадр без цикла
анимации.

### Перенос в React

Движок не знает про DOM-фреймворк, поэтому обёртка тривиальна:

```jsx
function ParticleBackdrop() {
  const ref = useRef(null);

  useEffect(() => {
    const field = new ParticleField(ref.current);
    field.start();
    return () => field.destroy();
  }, []);

  return <canvas ref={ref} className="space__particles" />;
}
```

## Отличия от макета

- **Кнопки скруглены.** В макете `border-radius: 0`; здесь `18px` на десктопе и
  `14px` на мобиле. Добавлены стеклянный фон, ховер с подъёмом и подсветкой,
  сдвиг стрелки и световой блик у основной кнопки.
- **Шаг между кнопками** 10px вместо 8px — со скруглёнными углами так читается
  чище.
- **Опечатка в тексте.** В макете «Вернутся на главную», в коде — «Вернуться на
  главную».
- **Фон** собран градиентами вместо растра, см. раздел выше.
