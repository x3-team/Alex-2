# Обложка Alex — Immunotech / Geotar (165×240 mm)

## Что отдавать в типографию

| Файл | Назначение |
|------|------------|
| **`alex-cover-165x240-bleed20-cmyk-vector.eps`** | **Векторный EPS.** Шрифты в кривых, изображения внедрены, чёрный K100 |
| **`alex-cover-165x240-bleed20-cmyk-300dpi.tif`** | **Растровый вариант.** CMYK, 300 dpi, 205×280 mm |
| `alex-cover-165x240-bleed20-300dpi.pdf` | Проверка размеров: 205×280 mm, TrimBox 165×240 mm, BleedBox во весь лист |
| `alex-cover-165x240-preview.jpg` | Экранный просмотр (soft-proof FOGRA39) |
| `print-check-report.json` | Отчёт автопроверок последней сборки |

EPS и TIFF — один и тот же макет, можно отдавать любой. Обрез в обоих ровно
**165 × 240 mm**. Лист EPS — 204,96 × 280,11 mm (вылет 19,98 / 20,05 mm вместо
ровно 20): `pdftocairo` округляет BoundingBox до целых пунктов, и лист положен
на целые пункты, чтобы макет не сползал внутри бокса. На вылет в 20 mm это не
влияет, обрезной формат точный.

Исходник — `src/cover-figma-source.pdf`, экспорт фрейма Figma
`165×240 · для типографии (205×280, без меток)` (`5010:759`).

Пересборка: `python3 docs/print/build_cover_print.py`
(нужны `pymupdf`, `pillow`, `numpy`, `opencv-python-headless`, `qrcode`).

## Геометрия

- Обрез **165 × 240 mm**
- Вылет **20 mm** с каждой стороны (переплётная обложка) → лист **205 × 280 mm**
- Наборное поле **145 × 220 mm** (10 mm от обрезного края)

## Правки по замечаниям издательства от 18.09.2026

| Замечание | Что сделано |
|-----------|-------------|
| Элементы и текст не должны выходить за наборное поле 145×220 | Макет уменьшен на 8% от центра обреза. Иначе не проходила нижняя строка «РЕКЛАМА…»: она была 155,8 mm шириной при поле 145 mm, сдвигом это не лечится |
| Серые линии должны выходить за обрез на 20 mm | Линии рамки продлены до края листа. В исходнике они обрезались ровно по резу |
| Обрезное поле залито серым | Вылет теперь чистый белый. Серость давала заливка `#FCFCFC` во весь лист |
| Логотип — 100% чёрный | Был `#1F1F1F` → C79 M70 Y55 K96. Стал **C0 M0 Y0 K100** |
| QR — 100% чёрный | Был C100 M88 Y51 K100 (339% краски). Стал **C0 M0 Y0 K100** |
| Тонкая серая рамка вокруг QR | QR перерисован из своей же ссылки в чистый растр по модульной сетке, рамка панели больше не рвётся |
| Нужен CMYK, а не RGB | Файл CMYK (FOGRA39). Нейтрали разделены **только по K**, поэтому суммарная краска на чёрном ровно 100% |
| Форматы eps / tif / psd | Есть векторный EPS и TIFF |
| «В присланном eps картинка в один слой» | Новый EPS — настоящий вектор. Прошлый сплющивался, потому что `eps2write` растрирует страницу с прозрачностью; здесь прозрачность разрешена в исходнике, а конвертация идёт через `pdftocairo` |

Дополнительно исправлено (в замечаниях не было, но ломало печать):

- **Физический размер.** В отправленном PDF/EPS `MediaBox` был 1291×1763 pt = **455×622 mm**: Figma отдаёт 1 px = 1 pt. Теперь ровно 205×280 mm.
- **Не было TrimBox/BleedBox** — из файла не читалось, где рез. В PDF проставлены.
- **QR был JPEG 410×410 в RGB** — артефакты сжатия по краям модулей. Перерисован без потерь; ссылка сверяется с оригинальной при каждой сборке.
- Шрифты: в EPS переведены в кривые (п. 4 техтребований), в TIFF отрастрированы (п. 7).

## Прозрачность

В исходнике Figma было 290 полупрозрачных заливок, две маски-клипа по резу и 17
картинок с альфа-каналом. Всё это разрешено в непрозрачные эквиваленты: над
белым листом заливка с прозрачностью `α` тождественна сплошной заливке цветом
`1 − α·(1 − c)`, маски-клипы совпадают с нашим клипом по резу, альфа картинок
впечатана. Без этого EPS не может остаться векторным.

## Автопроверки сборки

`build_cover_print.py` падает или пишет в отчёт, если что-то из этого нарушено:

- вылет без краски (никакого серого фона);
- ни одного элемента в 10 mm от реза, кроме линий рамки, которым положено уходить в вылет;
- линии рамки доходят до края листа;
- сплошной чёрный = ровно `0/0/0/100`;
- суммарное покрытие краски (норма Geotar ≤ 330%);
- QR из готового файла декодируется и совпадает со ссылкой из исходника.

Проверки гоняются отдельно по TIFF и по самому EPS (он для этого растрируется
обратно). Текущие значения — в `print-check-report.json`. Суммарная краска
максимум **116%** в TIFF и **130%** в EPS.
