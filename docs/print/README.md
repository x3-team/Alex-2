### Размер

- Печатный фрейм: **1574 × 2042 px** (обрез 1322 × 1790 + **126 px ≈ 20 mm** с каждой стороны).
- Экспорт **300 dpi** по ширине 250 mm: масштаб **1.876**.

Повторный экспорт: фрейм `4967:1156`, PNG/PDF @ 1.876 → CMYK TIFF со скриптом `match_greens_cmyk.py` (профиль `FOGRA39L.icc`).

### Зелёные как на мониторе

Автоконвертация RGB→CMYK серит зелёный. В TIFF закреплены два цвета макета так, чтобы **просмотр CMYK совпал с RGB на экране**:

| Где | RGB | CMYK (FOGRA39) |
|-----|-----|----------------|
| «300+ аллергенов», «бесплатно», средние точки чипа | `#97ae96` | C 33.7 / M 3.9 / Y 36.1 / K 25.9 |
| Светлые точки чипа | `#d2e8d1` | C 22.0 / M 0 / Y 23.9 / K 0 |

На тираже цвет ещё зависит от бумаги и профиля типографии (FOGRA39 ≈ мелованная бумага). Яркий RGB-зелёный, которого нет в CMYK, повторить 1:1 нельзя — эти два цвета в гамму входят.
