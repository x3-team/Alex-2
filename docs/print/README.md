## Геометрия

- Обрез **165 × 240 mm**
- Вылет **20 mm** с каждой стороны (переплётная обложка) → лист **205 × 280 mm**
- Наборное поле **145 × 220 mm** (10 mm от обрезного края)

## Правки по замечаниям издательства от 18.09.2026

| Замечание | Что сделано |
|-----------|-------------|
| Элементы и текст не должны выходить за наборное поле 145×220 | Макет уменьшен на 8% от центра обреза. Иначе не проходила нижняя строка «РЕКЛАМА…»: она была 155,8 mm шириной при поле 145 mm, сдвигом это не лечится |
| Серые линии должны выходить за обрез на 20 mm | Линии рамки продлены до края листа. В исходнике они обрезались ровно по резу |
| Обрезное поле залито серым | Вылет теперь чистый белый. Серость давала заливка `#FCFCFC` во весь лист |
| Логотип — 100% чёрный | Был `#1F1F1F` → C79 M70 Y55 K96. Стал **C0 M0 Y0 K100** |
| QR — 100% чёрный | Был C100 M88 Y51 K100 (339% краски). Стал **C0 M0 Y0 K100** |
| Тонкая серая рамка вокруг QR | QR перерисован из своей же ссылки в чистый растр по модульной сетке, рамка панели больше не рвётся |
| Нужен CMYK, а не RGB | Файл CMYK (FOGRA39). Нейтрали разделены **только по K**, поэтому суммарная краска на чёрном ровно 100% |
| Форматы eps / tif / psd | Основной файл — TIFF |

Дополнительно исправлено (в замечаниях не было, но ломало печать):

- **Физический размер.** В отправленном PDF/EPS `MediaBox` был 1291×1763 pt = **455×622 mm**: Figma отдаёт 1 px = 1 pt. Теперь ровно 205×280 mm.
- **Не было TrimBox/BleedBox** — из файла не читалось, где рез. В PDF проставлены.
- **QR был JPEG 410×410 в RGB** — артефакты сжатия по краям модулей. Перерисован без потерь; ссылка сверяется с оригинальной при каждой сборке.
- Шрифты в растре, как требует п. 7 техтребований для tif/psd.

## Автопроверки сборки

`build_cover_print.py` падает или пишет в отчёт, если что-то из этого нарушено:

- вылет без краски (никакого серого фона);
- ни одного элемента в 10 mm от реза, кроме линий рамки, которым положено уходить в вылет;
- линии рамки доходят до края листа;
- сплошной чёрный = ровно `0/0/0/100`;
- суммарное покрытие краски (норма Geotar ≤ 330%);
- QR из готового файла декодируется и совпадает со ссылкой из исходника.

Текущие значения — в `print-check-report.json`. Суммарная краска максимум **116%**.
