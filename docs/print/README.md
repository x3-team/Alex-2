# Обложка Alex — файлы для типографии (Geotar)

Макет-источник: Figma, страница **«Книга Alex»**, фрейм **«A4 · финальный макет обложки»** (`4723:119`).

## Готовые файлы

| Файл | Назначение |
|------|------------|
| `alex-book-cover-geotar-300dpi-cmyk.tif` | **Основной растровый макет** для передачи в препресс: CMYK, 300 dpi, без альфа-канала, LZW |
| `alex-book-cover-export-300dpi.pdf` | PDF из Figma (вектор + растр); запасной вариант |
| `alex-book-cover-export-300dpi-rgb.png` | RGB-экспорт для проверки (не для печати) |
| `geotar-prepress-requirements.pdf` | Требования Geotar к рекламным макетам |

### Размер холста

- **2954 × 3999 px** при **300 dpi** ≈ **250 × 337 mm** (формат A4 **210 × 297 mm** + **20 mm** вылета с каждой стороны для переплёта обложки, см. требования Geotar).
- Линии реза и уголки обреза в Figma **скрыты** в экспорте.

## Соответствие требованиям Geotar

| Требование | Статус |
|------------|--------|
| Растр ≥ 250 dpi (желательно 300) | ✅ 300 dpi |
| CMYK, без плашечных | ✅ CMYK TIFF (проверить профиль в типографии) |
| Вылеты: 5 mm / **20 mm для обложки** | ✅ заложено в размере холста макета |
| Шрифты в кривые | ⚠️ в TIFF текст растрирован; для **EPS** нужен экспорт из Illustrator/InDesign с outline |
| Безопасное поле ≥ 10 mm от обреза | ⚠️ сверить QR, дисклеймер и логотипы по макету |
| Серия «Тактика врача»: 15 mm слева/справа под пружину | ⚠️ уточнить у издателя, относится ли к этой книге |
| Суммарное покрытие ≤ 330% | ⚠️ не замерялось автоматически — при необходимости проверить в Acrobat |
| Overprint для 100% K | ⚠️ для растрового TIFF не применимо; для векторного PDF/EPS — в DTP |
| Форматы eps / tif / psd | ✅ TIFF; PDF приложен |

Вопросы в препресс: **prepress@geotar.ru**

## Повторный экспорт из Figma

1. Открыть фрейм `4723:119`, убедиться, что слои меток обреза скрыты.
2. Экспорт **PNG или PDF**, масштаб **2.234** (≈ 300 dpi для ширины 250 mm).
3. PNG → CMYK TIFF: см. команду в истории коммита или `convert … -density 300 -colorspace CMYK`.
