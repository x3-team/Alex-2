### Размер экспорта

- **2953 × 3831 px** @ **300 dpi** (ширина ≈ **250 mm** с вылетами; высота по пропорциям текущего макета).
- Вылет **126 px** ≈ **20 mm** (масштаб макета: 210 mm = 1322 px).
- В зоне вылета наращены: поле точек `graphic/field` (влево и вниз), декоративные линии рамки; остальное — белый фон.

## Соответствие Geotar

| Требование | Статус |
|------------|--------|
| Растр ≥ 300 dpi | ✅ |
| CMYK TIFF | ✅ |
| Вылет 20 mm для обложки | ✅ отдельный печатный фрейм |
| Шрифты в кривые | ⚠️ в TIFF — растрирование |
| Безопасное поле ≥ 10 mm | ⚠️ проверить по макету |
| EPS + overprint | ⚠️ при необходимости — Illustrator |
