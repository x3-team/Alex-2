# Обложка Alex — файлы для типографии (Geotar)

## Figma (страница «Книга Alex»)

| Фрейм | Назначение |
|-------|------------|
| **A4 · финальный макет обложки** (`4723:119`) | Рабочий макет без вылетов. Не менять. |
| **A4 · обложка · печать (+20 mm вылет)** (`4967:1156`) | Копия текущего макета + **20 mm** белого вылета с каждой стороны. Содержимое не правилось. |

## Файлы (экспорт печатного фрейма)

| Файл | Назначение |
|------|------------|
| `alex-book-cover-geotar-300dpi-cmyk.tif` | Для препресса: CMYK, 300 dpi |
| `alex-book-cover-export-300dpi.pdf` | PDF из Figma |
| `alex-book-cover-export-300dpi-rgb.png` | RGB для проверки |
| `geotar-prepress-requirements.pdf` | Требования Geotar |

### Размер

- Печатный фрейм: **1574 × 2042 px** (обрез 1322 × 1790 + **126 px ≈ 20 mm** с каждой стороны).
- Экспорт **300 dpi** по ширине 250 mm: масштаб **1.876**.

Повторный экспорт: фрейм `4967:1156`, PNG/PDF @ 1.876 → CMYK TIFF (`convert … -density 300 -colorspace CMYK`).
