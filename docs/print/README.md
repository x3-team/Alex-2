# Обложка 165×240, векторный CMYK

Файлы для печати по фрейму Figma `5000:1645` (лист с вылетом 20 мм).

- `alex-cover-165x240-bleed20-cmyk-vector.eps` — EPS LanguageLevel 2, только вектор, DeviceCMYK
- `alex-cover-165x240-bleed20-cmyk.pdf` — тот же рисунок в PDF 1.4
- `build_cover_vector.py` и `src/` — исходные контуры и повторная сборка

## Формат

- Обрез: 165 × 240 мм
- Лист: 205 × 280 мм, вылет 20 мм со всех сторон
- PDF MediaBox и BleedBox: `[0 0 581.102 793.701]`
- PDF TrimBox и ArtBox: `[56.693 56.693 524.409 737.008]`
- EPS `%%BoundingBox: 0 0 582 794` содержит `%%HiResBoundingBox: 0 0 581.102 793.701`

Масштаб равномерный: 1039 px макета = 165 мм. Левый верх обрезного поля стоит в 20 мм от левого и верхнего края листа.

## Цвет

Значения заданы как DeviceCMYK, цифрами под FOGRA39. Профиль в файл не вшит: пластины уже в этих процентах.

- Логотип и модули QR: 0/0/0/100
- Основной текст: 0/0/0/59
- Строка «РЕКЛАМА…»: 0/0/0/77, непрозрачность 1
- Линейки: 0/0/0/21
- Зелёный чипов, «300+», «бесплатно» и акцентные точки: 33.7/3.9/36.1/25.9
- Светлая сетка точек: только чёрная краска
- Вылет и лист: 0/0/0/0

Текст в кривых. В файле нет шрифтов, растровых картинок, RGB и прозрачности.

Шестнадцать размытий около 0,13 мм сняты: точки нарисованы сплошной заливкой, чтобы файл не проходил через сведение прозрачности.

Нижние горизонтальные линейки идут на всю ширину листа. Вертикальные не выходят в нижний край.

QR ведёт на главную пациентской версии. В ссылке стоят метки `utm_source=book` и `utm_medium=food_allergy`.

## Сборка

```bash
python3 docs/print/build_cover_vector.py
```

Скрипт заново пишет EPS и PDF рядом с собой. Не прогоняйте EPS через Ghostscript `eps2write`: это сведение, а файл уже плоский вектор.

Онлайн-иллюстратор EPS не открывает. Для просмотра и правки откройте PDF: это тот же макет, с TrimBox и BleedBox. EPS оставлен для типографии и собран только из команд, которые понимает десктопный Illustrator: без `rectclip`, `clip` и `showpage`.
