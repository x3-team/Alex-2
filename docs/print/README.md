# Обложка Alex — Immunotech / Geotar (165×240 mm)

## ТЗ типографии

- **Обрез:** **165 × 240 mm**
- **Вылет обложки:** **20 mm** с каждой стороны → **205 × 280 mm** размер файла
- Требования: `geotar-prepress-requirements.pdf`

## Figma (страница «Книга Alex»)

| Фрейм | Назначение |
|-------|------------|
| `A4 · финальный макет обложки` (`4723:119`) | Старый artboard (~210 mm), **не для этой книги** |
| **`165×240 · финальный макет обложки`** (`4975:1156`) | Обрез **165×240 mm**; дизайн масштабирован с A4 по ширине |
| **`165×240 · обложка · печать (+20 mm вылет)`** (`4975:1920`) | Файл для типографии + метки реза |

Пропорции A4 и 165×240 различаются: после масштаба по ширине сверху/снизу в обрезе ~**8 mm** белого поля — при необходимости доработать вёрстку в Figma.

### Размер экспорта

- **2421 × 3307 px** @ **300 dpi** = **205 × 280 mm** (с вылетом)
- **Обрез:** **165 × 240 mm** (между метками реза)
- Экспорт Figma: фрейм `4975:1920`, масштаб **1.875**

Зелёные: `match_greens_cmyk.py` + `FOGRA39L.icc` (#97ae96, #d2e8d1).
